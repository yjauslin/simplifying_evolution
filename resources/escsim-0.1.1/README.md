# escsim

A command line tool simulate the parameters for the extended structured
coalescent. It can simulate or calculate the fitness classes as provided
by Nicolaisen and Desai (2012).

## Installation

Install the package in development mode:

```bash
pip install -e .
```

Or install from the package:

```bash
pip install .
```

## Usage

After installation, you can use the `escsim` command from anywhere:

```bash
escsim --help
```

## Development

To install in development mode with dependencies:

```bash
pip install -e .
```
